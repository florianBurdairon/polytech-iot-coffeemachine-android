# Projet IoT : Coffee Machine
## Partie Android
Afin de pouvoir tester l'application sur votre smartphone, vous pouvez suivre ce lien : **https://appdistribution.firebase.dev/i/cae6b2eb7c0360f4** qui va permettre de télécharger l'apk de l'application. Il suffit de renseigner une adresse mail pour accéder au téléchargement.

En effet le code disponible sur le repository **CoffeeMachine_Android** ne peut directement être utilisable (c'est-à-dire qu'en passant par Android Studio pour installer l'application sur le téléphone certaines fonctionnalités en lien avec l'accès à Firebase ne fonctionneront pas). La connection à Firebase nécessite de générer ce qui s'appelle une empreinte qui sécurise la connexion entre l'application et Firebase (afin que personne ne puissent modifier les tables de la base juste en ayant à disposition l'application Android). Or cette empreinte (un fichier correspondant à un certificat SHA-1) est à chaque fois générée depuis Firebase par le propriétaire de la base et doit être télécharger dans Android Studio afin que le nouvel utilisateur de l'application puisse installé l'application sur son smartphone.
